## Features (OpenXR Games)

- **Head gesture to switch presets:** raise a hand to the side of your head and press a button to switch to the next preset, for example from a preset for dark scenes to one for bright scenes. If you only have one preset, the gesture turns effects on and off.
- **Share presets between games:** save a preset as global, then import it in another game. Effects that game lacks are copied along. Starred effects can be added the same way.
- **Walk by swinging your arms:** swing your arms to walk, and swing faster to run. For games that walk with the left thumbstick.
- **Pin the menu:** keep it to one side, out of your way.
- **Pin the FPS counter:** always see your FPS, even with the menu closed.
- **Settings for all games:** set menu buttons, gestures and pin once. Switch off **Use shared settings** where one game needs different ones.
- **Safe start:** if a game crashes while starting, the add-on switches itself off for that game. `Re-enable-Games.cmd` turns it back on.
